Problem: User logons and logoffs were unlogged, resulting in a lack of auditablitiy and security.

The Fix:  Configured Advanced Audit Policies to monitor for unauthorized access. 
Successfully simulated a brute-force credential attack and identified the resulting Event ID 4625 (Logon Failure) in the Windows Security Event Log.
